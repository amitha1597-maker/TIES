# TIES – Tactical Intelligence Explainability System

אב-טיפוס לימודי (MVP) של מערכת להנגשת מודיעין והסברתיות טקטית: מפקד בוחר נקודת מוצא ויעד, מקבל שתי חלופות ציר עם מטריצת השוואת סיכונים וכרטיסיית הסברתיות לכל איום, בוחר ציר ומדווח משוב שטח בלחיצה אחת.

**כל הנתונים מדומים לחלוטין:** הגזרה (מפה סכמטית בדויה), היחידה, המקורות, האיומים והתרחיש.

## הרצה

קובץ אחד, `index.html`, בלי תלויות חיצוניות. אפשר לפתוח אותו ישירות בדפדפן, וגם בלי חיבור לאינטרנט.

## מה יש באב-הטיפוס

- זרימה בחמישה שלבים: מוצא ויעד, עיבוד אד״ן וסינון ידיעות, אישור קמ״ן, השוואה והחלטה, משוב שטח.
- מנוע מסלולים (Dijkstra) שמפיק ציר מהיר וציר עוקף, ושקלול סיכון: חומרה × הסתברות × אמינות המקור.
- הדמיית Offline ו-Delta Sync, ועדכון בייסיאני של משקלי אינדיקציות במצב תחקיר.
- לוח מדדים: זמן החלטה, הפחתת התראות, זמן דיווח שטח ומדד אמון.
